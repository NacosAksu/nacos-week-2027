## ✨ Features

- **Editorial Festival Visual Identity**: Clean, flat colour fields (`#005012`, `#089002`, `#F5F7F2`, `#E6F2E3`), 1px hairline rules, monospace numerals, and human-centred typography with zero generic gradient bloat.
- **14 Editorial Sections**:
  1. `01 — The Gathering`: Philosophy & purpose of NACOS Week.
  2. `02 — The Four Days`: Comprehensive 4-day festival schedule with interactive tabs & expandable speaker session details.
  3. `03 — Editorial Lineup`: Featured keynote leaders, founders, and engineers.
  4. `04 — Why Be In The Hall`: Value propositions for students, builders, and graduates.
  5. `05 — The Confluence Hackathon`: 24-hour hackathon details, tracks, rules, and prizes.
  6. `06 — The Work`: Project showcase and student builder exhibition.
  7. `07 — Delegate Passes`: Registration tiers (Student, Delegate, All-Access Fellow) with interactive registration modal and simulated pass generation.
  8. `08 — The Ground`: Venue directions, transit info, and live embedded Google Map.
  9. `09 — Sponsors & Allies`: Departmental, industry, and alumni partners.
  10. `10 — Voices from Previous Years`: Testimonials from past NACOS graduates and fellows.
  11. `11 — The Leadership`: NACOS AKSU executive board and planning committee.
  12. `12 — Questions Answered`: Accordion FAQ covering attendance, certification, and participation.
  13. `13 — Live Broadcast`: Streaming schedule and remote access channels.
  14. `14 — Final Invitation`: Last registration call to action and countdown timer.
- **Interactive Functionality**:
  - Live countdown timer to February 1, 2027 (10:00 AM WAT).
  - Day 1–4 tab switcher with accordion details for each talk.
  - Multi-tier registration modal with ticket summary, validation, and delegate pass generation.
  - Dynamic FAQ accordion and live toast notification feedback.

## 🚀 Getting Started Locally

No complex dependencies or build steps required. Simply serve the directory with any standard HTTP static file server:

```bash
# Using Python 3:
python -m http.server 3000

# Using Node.js npx serve:
npx serve .
```

Then open `http://localhost:3000` in your web browser.

## 🏛️ About NACOS AKSU

The **National Association of Computing Students (NACOS)**, Akwa Ibom State University Chapter, is the umbrella body for all computing, software, and technology students at AKSU. NACOS Week is its annual flagship event.
